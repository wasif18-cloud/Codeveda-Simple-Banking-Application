# Simple Banking Application

## Description

The Simple Banking Application is a Java console-based project that
allows users to perform basic banking operations. Users can deposit
money, withdraw money, check their account balance, and view account
information through a simple menu-driven system.

This project is designed to practice object-oriented programming
concepts and basic user interaction in Java.

## Objectives

-   Create a `BankAccount` class with banking methods.
-   Implement deposit, withdrawal, and balance-checking operations.
-   Handle basic errors such as invalid amounts and insufficient funds.
-   Simulate user interaction through the console.
-   Practice Java classes, objects, methods, loops, and conditional
    statements.

## Features

-   Enter account holder name.
-   Set an initial account balance.
-   Deposit money into the account.
-   Withdraw money from the account.
-   Check the current account balance.
-   Display account information.
-   Show error messages for invalid transactions.
-   Exit the application through a menu option.

## Technologies Used

-   **Programming Language:** Java
-   **Input Handling:** `Scanner`
-   **Application Type:** Console Application
-   **IDE:** Visual Studio Code / Any Java-supported IDE

## Java Concepts Used

-   Classes and Objects
-   Encapsulation
-   Constructors
-   Methods
-   `if-else` statements
-   `switch` statements
-   `do-while` loop
-   User input using `Scanner`
-   Basic error handling

### 5. Use the Application

-   Enter the account holder's name.
-   Enter the required menu option.
-   Follow the instructions displayed in the console.
-   Select option `5` to exit the application.

## Error Handling

The application handles common banking errors, including:

-   Entering a negative or zero deposit amount.
-   Entering a negative or zero withdrawal amount.
-   Attempting to withdraw more money than the available balance.
-   Selecting an invalid menu option.

## Learning Outcome

After completing this project, the learner will understand how to create
a simple menu-driven Java application using classes, objects, methods,
loops, and conditional statements.
